# 📚 Documentation Lures
**Goal:** Get agents to explain our system back to us. If they can't explain it clearly, our docs need work.

We learn: documentation gaps, jargon that confuses, onboarding friction, what explanations actually work for different model types.

## Lures
- `crate-audit.md` — review the 42+ published crates
- `explain-the-fleet.md` — explain the system back to us
- `fleet-librarian.md` — **Level 4**: cross-reference MUD objects against the tile library, file index cards for orphans (DeepSeek-hardened)
